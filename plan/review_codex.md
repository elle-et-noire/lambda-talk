1. **中：β 代入で置き換える出現の範囲が未定義。**

   位置：p.17、`slides/lambda.md:352`、353、発表者ノート 359。

   「本体 M の中の x を、引数 N で置き換える」では、内側の λx に束縛された x まで置換すると読める。置換対象は M における x の自由な出現だけである。たとえば `(λx.λx.x) a` の結果は `λx.x` であり、`λx.a` ではない。「名前がぶつかるなら α変換」という説明だけでは、この束縛の境界を指定できていない。

   修正：352 行を「本体 M における x の**自由な出現だけ**を、引数 N で置き換える」に変更し、353 行を「M[x := N] は**変数捕獲を避ける代入**。内側の λx に束縛された出現は置き換えない」とする。ノート 359 にも同じ限定を入れる。[Selinger, §2.3](https://www.mathstat.dal.ca/~selinger/papers/lambdanotes.pdf)

2. **中：IF の表の矢印は単一の β ステップではない。**

   位置：p.29、`slides/lambda.md:624`、625、ノート 632。

   `IF TRUE a b` から `TRUE a b` には、IF の 3 個の引数を受け取る 3 ステップが必要。`TRUE a b` から a も 2 ステップ必要であり、両行の `\to_\beta` は誤り。

   最小修正：624・625 行の `\to_\beta` をともに `=_\beta` に置換し、「各行は複数ステップの β 簡約をまとめた β 同値」を本文とノートに明記する。単一ステップで見せるなら次の列に置き換える。

   ```text
   IF TRUE a b
   →β (λt.λf.TRUE t f) a b
   →β (λf.TRUE a f) b
   →β TRUE a b
   →β (λf.a) b
   →β a
   ```

3. **中：POW の表でも複数ステップを単一ステップと表示している。**

   位置：p.47、`slides/lambda.md:1004`。

   修正：1004 行左端の `\to_\beta` を `=_\beta` に変更する。行中の `3̄ 2̄ f = 2̄ (2̄ (2̄ f))` の等号も、β 同値であることがわかるよう `=_\beta` とする。1005 行の f の合成回数を表す等式とは区別する。

4. **中：SKI の表と ω の確認式で、組合せ子の規則と単一 β 簡約を混同している。**

   修正：2193・2194・2256・2265 行と、2328 行の 2 個の `\to_\beta` を `=_\beta` に置換する。あるいは S・K・I の**組合せ子簡約規則**を別に定義し、矢印を `\to_S`、`\to_K`、`\to_I` として使う。2266 行の `I b →β b` は、数学側の定義 I = λx.x を使うなら変更不要。

5. **中：Python の値呼びと、λ計算の完全な簡約戦略を同一視している。**

   位置：p.23、`slides/lambda.md:496`、497；p.24、509、ノート 526；p.33、ノート 716；p.70、1496、1497、1506、ノート 1508。

   正規順序は最左・最外の簡約基を選び、正規形まで求める際には λ の本体内も簡約する。「引数は使うまで計算しない」は実用言語の弱い名前呼び・遅延評価に近い説明であり、正規順序全体の定義ではない。同様に、適用順序を最左・最内の簡約とするなら、Python の値呼びとは λ の下の扱いが異なる。Python で `lambda x: omega(omega)` は作成できるが、その λ 項を完全な正規順序・適用順序で簡約すると、本体の Ω が停止しない。

   修正：509 行の見出しを「Python は正格評価（値呼び）」に変更。1496 行を「Python は値呼び：引数を値まで評価してから呼ぶ。lambda の本体は呼ぶまで評価しない」、1497 行を「正規順序：最左・最外の簡約基から簡約する。正規形を求めるときは λ の本体内も対象」とする。496・497 行の順番も「最左・最外」「最左・最内」と明記する。1506 行は「正規順序なら (Y F) ZERO は fact を使わずに ONE まで簡約できる」と、引数を与えた項に限定する。関連ノートでも「Python は適用順序そのもの」という断言を避ける。[Python 言語リファレンス](https://docs.python.org/3/reference/expressions.html#calls)、[Ker, §3.1–3.2](https://www.cs.ox.ac.uk/andrew.ker/docs/lambdacalculus-lecture-notes-ht2009.pdf)

7. **中：SUB のヒントと説明が、SUCC の置換だけでよいとして引数の反転を落としている。**

   位置：p.56、`slides/lambda.md:1194`；p.57、1211。

   修正：1194 行の該当箇所を「ADD は『n に SUCC を m 回』でした。SUB は『m に PRED を n 回』なので、関数を替えるだけでなく、m と n の役割も入れ替えます」に変更。1211 行を「m に PRED を n 回適用する。ADD と比べて SUCC を PRED に替え、m と n の役割を逆にした形」とする。
