## A. スライド本文（slides/lambda.md）— Claude が反映

### 正しさ（Codex）
- C1 採用：β簡約の代入は「自由な出現だけ」。p.17 本文とノート。
- C2/C3/C4 採用（表記を変える）：複数ステップは $\twoheadrightarrow_\beta$（↠β、「β簡約を何回か」）で表す。1 ステップの $\to_\beta$ は 2 章の手順表だけで使う。↠β は初出（p.29 の IF）で 1 行説明する。p.47 の POW、p.99 / p.101 / p.103 の SKI も同様。β同値の等式（展開を含む）は $=_\beta$。
- C5 採用（初学者向けに簡潔に、ただし不正確にしない）：
  - 正規順序 (normal order)：いちばん外側・左の簡約基から。適用順序 (applicative order)：いちばん内側・左（引数）から。
  - Python は「値呼び (call by value)」＝正格評価 (strict evaluation)：引数を値まで計算してから呼ぶ。**ただし lambda の中身は呼ばれるまで計算しない**。これがサンクと Z が効く理由だと結びつける（P の「適用順序＝正格」の対応づけ要望もここで満たす）。
  - p.24 見出し「Python は正格評価（値呼び）」。p.70 の 2 行、p.70 の「正規順序なら止まる」は「正規順序なら `Y F ZERO` は fact を使わずに ONE まで簡約できる」に限定。
- C6 採用：p.33 ノート、ω → Ω。
- C7 採用：SUB のヒントと解答の説明（引数の役割も入れ替える）。
- C8 採用：p.68 ノートの文言。
- C9 採用：MOD/DIV スライドに「前提：除数 n は 1 以上」。
- C10 採用：`ADD(1)(...)` → `ADD(ONE)(ADD(TWO)(...))`。p.64 の図は ONE/TWO/THREE で書き、名前は F ではなく G（P の高 1）。
- C11 採用：SKI は「閉じた項（自由変数のない項）なら S・K・I と適用だけ」。p.102、p.105、ノート。
- C12 採用：性能説明は「SUCC・ADD の鎖は深くなる。MUL・POW の合成は値の大きさと深さが比例しない。FACT 11 の境界は時間」。
- C13 採用：FizzBuzz の上限は「再帰上限 1000 のままで 240 程度まで（実測：通常実行 247、検証スクリプト経由 246）」。
- C14 採用：チャーチ＝チューリングのテーゼを「機械的な手順で計算できる関数」に限定。根拠は「独立に提案された主要なモデル（λ計算、チューリング機械、一般再帰関数）が同じ範囲を与えた」。
